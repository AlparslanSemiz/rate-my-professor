# Planning documents

The team's planning repository from the start of the PSE course, kept here for history. Some of it describes an **early design** that changed later: the first server was Node.js with Prisma (`SCHEMA.md`, `CICD.md`); the final backend is Spring Boot (see [`../../backend/`](../../backend/)).

| File | What |
| --- | --- |
| [`user-stories.md`](user-stories.md) | User stories by role (student, user, professor, moderator) |
| [`diagrams/`](diagrams/) | PlantUML sequence and domain diagrams of the app's main flows |
| [`SCHEMA.md`](SCHEMA.md) | The first database schema (Prisma, PostgreSQL) |
| [`deployment-overview.md`](deployment-overview.md) | How backend, admin panel and app were deployed together |
| [`CICD.md`](CICD.md) | Notes on the first GitLab CI/CD pipeline |
| [`backend/ReadMe.md`](backend/ReadMe.md) | Setting up the course server on bwCloud |
| [`android/tests.md`](android/tests.md) | What the Android app's tests cover |

Links to `gitlab.kit.edu` point to the course's internal GitLab and are not public. Server addresses were removed.
